# Свои фотографии станции

Положите сюда JPG-файлы с такими именами — игра сама заменит ими нарисованные текстуры
(работает, когда сайт открыт по http/https, а не как локальный файл).

| Файл | Что это |
|---|---|
| `wall.jpg` | стены станции |
| `sign.jpg` | пилон с названием «Бәйтерек» |
| `train.jpg` | борт вагона LRT снаружи |
| `train_inside.jpg` | салон вагона |
| `door.jpg` | стеклянные двери |
| `gate.jpg`, `turnstile.jpg` | турникеты |
| `machine.jpg` | автомат продажи билетов |
| `escalator.jpg` | эскалатор |
| `column.jpg` | колонны |
| `cab.jpg` | дверь кабины машиниста (выход) |
| `floor.jpg`, `ceiling.jpg`, `edge.jpg`, `track.jpg` | пол, потолок, жёлтая полоса, путь |
| `city.jpg` | панорама города за стеклом (широкая, 360°, ~2048×256), например вид на Abu Dhabi Plaza |

Квадратные фото (кроме `city.jpg`) выглядят лучше всего — их масштабирует до 128×128.
